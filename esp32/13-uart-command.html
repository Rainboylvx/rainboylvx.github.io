本课完成后能做什么

  • 分两次发送 o 和 n 加换行，最终只执行一次 LED ON。
  • 一次粘贴 on、off 两行，依次执行；发送 help 显示帮助。
  • 发送超过 63 个字符的一行，得到 ERR line too long，随后正常命令仍可用。
  • 发送半行后等超过 2 秒，再发送命令，确认超时恢复。

从字节流到命令：不能把一次读取当一行

UART 没有“这一行已经发完”的概念。115200、8N1 表示每秒 115200 bit，8 个数据位、无校验、1 个停止位；连同起始位，一个字符约需 10 bit。设备可以收到 o，下一次才收到 n\n；也可能一次读到 on\noff\n。因此接收循环必须逐字节处理。

本例用 64 字节行缓冲，最多保存 63 个字符，最后一个位置留给 C 字符串结尾。遇到 CR 或 LF 才执行命令；连续的 CRLF 中，第二个结束符遇到空行，不会再次执行。超过容量后丢弃整行直到结束符，避免把非法长输入的前缀误认成合法命令。

两秒没有收到后续字符，会清除未完成的行。这是教学协议约定，不是 UART 硬件限制。每次 uart_read_bytes() 最多等待 20 ms，任务等待期间不占用 CPU，也不影响其他任务。

日志、回显和业务消息共用串口

连接板上的 UART USB 口，P4 将 U0RX 接 TXD、U0TX 接 RXD。不要误接只有原生 USB 功能的另一个接口。终端设置 115200 8N1，关闭本地回显；程序已经逐字节回显，再开启本地回显会显示两遍。

这里仅安装一份 UART0 驱动，不再让另一套 console REPL 抢读输入。启动日志和响应都会出现在串口中，适合人工实验；正式二进制协议应另开 UART 或明确分帧，不能让日志混入协议数据。

第 03 课用 BOOT 控制 GPIO1，这一课把输入来源换成命令，LED 的低电平有效关系没有变化。

工程如何组织

components/BSP/UART/serial.c 负责 UART 和板载 LED 初始化、收发；main/main.c 负责行缓冲、超时和命令分派。BSP 不认识 on/off 命令，应用也不用重复配置波特率。完整驱动见配套仓库。

固定引脚以 CONFIG_LESSON_* 常量写入本工程 Kconfig.projbuild，构建后可在 sdkconfig 核对；这些默认值对应本板连线，不表示任意改数字就能改变硬件。

应用代码：入口与处理流程

下面代码直接取自配套工程的 main/main.c，头文件和 BSP 实现在仓库中一并提供。初学时先看 app_main()，再追踪它调用的模块。

 1#include "sdkconfig.h"
 2#include <stdio.h>
 3#include <stdint.h>
 4#include <stdbool.h>
 5#include <string.h>
 6#include <stdlib.h>
 7#include <assert.h>
 8#include "esp_err.h"
 9#include "esp_log.h"
10#include "esp_timer.h"
11#include "freertos/FreeRTOS.h"
12#include "freertos/task.h"
13#include "serial.h"
14// UART 是字节流：一个 read 可能只含半条命令，也可能含多条命令。
15void app_main(void)
16{
17    ESP_ERROR_CHECK(serial_init());
18    char line[64]; size_t used=0; bool dropping=false;
19    int64_t last=esp_timer_get_time();
20    puts("Commands: on / off / help (press Enter)");
21    while(1) {
22        uint8_t bytes[64];
23        int n=serial_read(bytes,sizeof(bytes));
24        if((used || dropping) && esp_timer_get_time()-last>2000000) {
25            used=0; dropping=false;
26            puts("\r\nERR incomplete line timed out");
27        }
28        for(int i=0;i<n;i++) {
29            unsigned char c=bytes[i]; last=esp_timer_get_time();
30            serial_echo(c); // 终端关闭本地回显，避免显示两遍。
31            if(c=='\r' || c=='\n') {
32                if(dropping) puts("\r\nERR line too long");
33                else if(used) {
34                    line[used]=0;
35                    if(!strcmp(line,"on")) { serial_led(true); puts("\r\nLED ON"); }
36                    else if(!strcmp(line,"off")) { serial_led(false); puts("\r\nLED OFF"); }
37                    else if(!strcmp(line,"help")) puts("\r\non / off / help");
38                    else puts("\r\nERR unknown command");
39                }
40                used=0; dropping=false;
41            } else if(!dropping) {
42                if(c==8 || c==127) { if(used) used--; }
43                else if(c>=32 && c<127) {
44                    if(used<sizeof(line)-1) line[used++]=c;
45                    else dropping=true; // 整行丢弃，不能执行被截断的前缀。
46                }
47            }
48        }
49    }
50}

先检查目标是否是 esp32s3、实际端口与供电，再按本文引脚表核对跳线。编译成功只能说明源码与工具链兼容，无法证明模块型号、物理线路或时序已经正确。
