一个持续更新的精选资源列表，涵盖算法竞赛、数学、编程语言、计算机科学和在线工具。仿照 GitHub 上的 awesome 系列，按分类整理。

1 算法竞赛与 OJ

  • Codeforces — 全球最大的算法竞赛平台之一
  • AtCoder — 日本竞赛平台，题目质量极高
  • Luogu 洛谷 — 国内最大的 OJ 与算法社区
  • OI Wiki — 竞赛知识百科，覆盖几乎所有算法知识点
  • USACO Guide — 从入门到 IOI 的系统学习路径
  • CP-Algorithms — 竞赛算法大全（原 emaxx 俄文站英译）
  • Codeforces EDU — CF 官方教程，含二分、线段树、Suffix Array 等
  • CSES Problem Set — 经典的分类练习题库
  • VNOI Wiki — 越南 OI 社区的算法百科
  • Algorithms for Competitive Programming (PDF) — 《Competitive Programmer’s Handbook》免费电子书

在线评测与虚拟比赛

  • Virtual Judge — 聚合多家 OJ 的虚拟评测平台

  • Kattis — 开放式算法题库
